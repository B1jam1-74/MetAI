Binaries are made to be flashed on to the board by either using CubeProgrammer or by dropping the binary file on to the mass storage device that appears when the board is connected to the computer via USB. The binary files are located in the `Binaries` folder of this repository.

The Final project binary is the end project with all features implemented and tested.

The First AI model binary is the first AI model that was trained and tested on the board. It may not have all features implemented and may not be fully optimized since it only serves as a proof of concept for the AI model running on the board.

Finally, the Simple board test binary is a simple test binary that can be used to verify that the board is working correctly. It may not have any features implemented and is only meant to be used as a basic test to ensure that the board is functioning properly.
